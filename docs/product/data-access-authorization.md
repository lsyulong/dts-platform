# 数据权限申请、审批与查询授权

权限申请、审批决定、实际授权是三个不同对象。`data_access_request.status=approved` 保存历史审批决定，不能据此判断用户现在可以查询。当前可用授权必须满足真实用户仍启用、授权未过期/撤销、租户相同及元数据采集证明仍匹配。

## 申请与决定

申请关联当前租户实际采集的 `metadata_object`。服务端冻结完整字段定义、对象版本、采集指纹和真实数据库/Schema/表定位。申请的字段只能从真实字段中选择；未选字段表示申请创建时实际存在的全部字段，不会自动包含未来新增字段。

申请人来自登录会话。默认有效期为 30 天，最多 365 天。提交前的草稿和被驳回的申请可以由本人更新；更新后回到草稿。提交、批准、驳回、撤回、撤销使用版本和持久化幂等键，网络重试不能重复创建授权。相同幂等键使用不同动作、申请版本、调用人或意见时返回冲突。

状态流转为草稿 → 待审批 → 已批准/已驳回。申请人可以撤回草稿、待审批或已批准申请；撤回已批准申请会在同一事务撤销实际授权。审批者可以撤销已批准授权。已批准、已撤回、已撤销的定义不可直接改写成新范围。

批准、驳回和撤销要求当前租户真实有效用户具有明确的 `data_security:approve` 权限，并拒绝自行审批。批准有效期可以缩短申请有效期，不能延长。审批、授权创建/撤销、源申请状态、决定回执与审计同事务提交；仅修改申请状态不能获得查询授权。

## 查询检查

普通字段授权查询需要显式使用 `catalog.schema.table`。第一版支持单表 SELECT、投影表达式、WHERE、普通 GROUP BY、ORDER BY 及有界整数 LIMIT/OFFSET。所有引用字段均纳入授权检查，包含筛选、分组和排序中没有返回的字段。

允许的函数和表达式经过 AST 白名单检查；未知字段、外部表函数、子查询、CTE、多表 JOIN、集合操作、窗口、高级分组、任意函数和占位符会明确拒绝。星号不能带排除/替换等修饰。`*`、`COUNT(*)` 和不引用任何实际字段的常量查询要求冻结表的全部字段均已授权；`COUNT(actual_column)` 按实际字段检查。投影别名不能覆盖实际字段名称。

多个仍有效的授权可以合并同一冻结表的字段集合。服务端通过内部元数据仓储验证真实采集证明，不能单靠普通属性中的 `engine_binding` 获得执行权。元数据目录版本、指纹或物理定位变更后，旧授权不再有效；物理引擎的外部变更仍需真实采集反映到目录中，不能宣称持续监控了所有外部 DDL。

管理旁路必须同时满足真实系统 `tenant_admin` 角色和该角色明确授予的 `data_security:all_data` 权限。它仍需当前租户与分析引擎绑定、用户有效和只读 SQL 检查，不授予外部文件/表函数访问权。普通用户的 Schema 列表仅从当前有效授权生成，不通过任意 information_schema 查询暴露其他表。

质量执行器具有独立的内部授权入口。它重新读取真实持久化任务，核验运行租约、fence、取消状态、执行用户、节点及当前采集证明，再用固定质量编译器重新生成并逐字比较 SQL。普通用户只有该真实表全部字段的有效授权时才能运行这些受控 COUNT/窗口查询；用户自由 SQL 中的 CTE/窗口仍会拒绝。API 不能传入“可信查询”标签取得此入口。BI 的受控单表分组聚合可以使用字段授权，仍按所有维度和度量字段检查。

## 执行与审计

历史任务结果不继承原执行人的访问权。读取质量计数时按当前读者重新验证真实任务、固定编译器 SQL、成功节点结果及当前元数据证明；读者需要当前完整字段授权。质量结果、报告和监控汇总在统计和释放响应前检查相关成功节点，任一无权节点会拒绝整个响应，避免静默丢弃任务后输出不完整统计。

入口先取得不可由 API 构造的 `AuthorizedQuery`，在发送到分析引擎前以及释放结果前重新授权。执行期间用户停用、原授权撤销/过期或元数据变化时拒绝释放结果；后来新建的授权不能替代执行时已撤销的原授权。该检查不承诺物理中断已经发到独立分析引擎的查询。

所有 SQL 文档、工作流、质量/BI 查询以及自由查询出口必须接同一授权服务；缺少授权服务配置时拒绝执行。固定的内部元数据采集查询由专门的 `metadata:execute` 路径处理，不能通过用户 SQL 的一个标签绕过授权。

访问审计记录查询哈希、真实授权/元数据 ID、引用字段和实际成功/失败/拒绝结果，不保存 SQL 正文、字面量、申请目的或原敏感数据。审计写入失败时不能将执行过程报告为已完整成功。

## 验证

服务模块提供 AST、字段范围、别名遮蔽、SQL 字符串保真、幂等语义、过期/撤销/替代授权、当前元数据证明和租户身份的边界测试源码。SQLite/PostgreSQL 仓储事务与真实权限校验由各自仓储测试覆盖。当前交付阶段尚未运行这些新测试，也没有启动平台或进行整体 POC。
