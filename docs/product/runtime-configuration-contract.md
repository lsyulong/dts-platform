# 开发运行配置合同

## 实际消费范围

`development_config` 为 SQL 文档与开发工作流提供非敏感类型化变量、单节点查询超时和配置级并发上限。定义管理、纯校验、配置发布、开发定义发布、作业排队与真实执行分别记录。发布配置不执行 SQL，也不注册周期调度。

配置范围为 `shared` 或 `source`。共享配置不携带来源身份；指定来源配置必须绑定同租户真实的 `sql_document` / `development_workflow`。SQL 和流程通过可选 `configuration_id` 引用实际配置，不能把名称、客户端快照或手工状态当作发布证明。

运行变量最多 32 项、16 KiB，只允许标量值与显式 NULL。变量名须为受控标识，禁止秘密、连接串与凭据引用。目前只读执行器不消费运行凭据，因此不提供看似可保存但实际上无效的凭据引用流程。凭据的后续接入需有真实引擎消费者及独立授权合同。

## 参数与发布

参数优先级是定义默认值 → 已发布配置变量 → 本次运行覆盖。最终值由既有声明校验器和 AST 参数绑定器处理；未声明参数、错误类型、非只读 SQL 与 BIGINT 越界不能进入作业队列。前端传输超过 JavaScript 安全整数范围的 BIGINT 时使用精确十进制字符串。

指定来源配置发布前校验其真实来源和变量声明；共享配置在具体 SQL / 工作流发布时校验实际参数兼容性。配置发布要求实际 `development:read/write` 权限，开发定义发布另要求实际 `development:execute`。不能仅依靠客户端权限字段。

配置发布/撤回使用实际资源版本 CAS、原因、稳定 UUID 幂等键。发布快照、回执、资源状态与审计同事务提交。原请求重放返回原回执，但不会把后来撤回的当前配置恢复为已发布；HTTP 响应的顶层资源仍读取当前真实状态。

开发定义发布固定配置 ID、实际发布版本、完整资源哈希、超时与并发策略，并保存不可变来源绑定。配置变化后不能自动升级旧定义。必须重新审查和发布开发定义后才能采用新配置。

## 作业证据与失败关闭

运行提交固定已发布配置证据和最终参数。作业、节点及配置绑定同事务入队；客户端不能构造 `runtime_configuration` 证据。重试复用原快照并重新检查当前来源与配置，不能悄悄切换到新配置版本。

worker 在执行前、运行期间的授权边界与释放结果前重新检查配置。配置撤回、来源版本变化、配置哈希不符或当前权限失效时，不继续执行或释放结果。历史作业与真实节点结果保留；当前读者的受控投影隐藏失效结果，不将历史成功状态改成失败。CSV/JSON 导出通过同一个作业读取流程并在编码后重验。

## 并发与超时

并发上限为 1..16，计数基于同一租户、同一配置 ID 下实际 `running` 且数据库租约尚有效的作业，包括不同配置发布版本。SQL 文档和工作流共享配置时共享此上限；原有每来源仅一条活跃作业的约束仍适用。

配置并发占用直接复用作业的租约与 fence，没有独立的易失计数器。SQLite 使用 `BEGIN IMMEDIATE` 串行领取；PostgreSQL 在领取事务中锁定实际租户行，防止多个 worker 同时越过容量检查。正常终态、取消完成与租约过期释放容量；迟到的旧执行器不能续约或提交结果。

单节点超时为 1..60 秒，不能超过当前查询引擎硬上限。超时让控制面节点和作业记录真实失败，并停止等待该查询 future。远端查询是否被物理终止取决于引擎协议，不能宣称任意远端 SQL 都已强制取消。并发约束属于作业调度能力，不等同于分布式 DuckDB SQL。

## 持久化与界面

迁移 024 创建不可变配置发布、来源绑定、作业绑定和操作回执；SQLite 与 PostgreSQL 使用一致领域合同。启动时实际 SQLite 迁移执行器与生产 PostgreSQL 迁移路径均已注册。此次开发未迁移用户现有本地数据库、未启动平台服务。

绿色工作区支持共享/指定来源、真实来源对象选择、变量类型、NULL、超时/并发、纯校验及带原因的发布/撤回。新共享配置默认空变量对象，允许仅配置执行策略。运行弹窗读取真实已发布配置，默认继承参数，只提交用户勾选的本次覆盖；不把配置变量复制成新的客户端发布证据。

## 验证边界

SQLite 仓储专项验证发布原子性、不可改快照、幂等重放、真实权限与租户、来源范围、伪造证据拒绝、撤回保留历史、多 worker 容量和旧 fence 失效。服务专项覆盖真实参数合并、撤回前零查询、历史结果与导出关闭、查询超时和后续执行恢复。最终通过数以实施台账为准。

生产 PostgreSQL 运行、真实 SwanLake/DuckDB 查询与分布式故障恢复尚未开展整体 POC。周期调度、写节点和运行凭据消费者也不属于本合同已经实现的能力。
